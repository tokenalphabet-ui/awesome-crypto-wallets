## Hardware wallets

- [Ledger](https://www.ledger.com/) - Secure element hardware wallets with the Ledger Live app. [Explained](https://tokenalphabet.com/blog/ledger-explained-why-millions-trust-this-hardware-wallet-for-long-term-crypto-storage)
- [Trezor](https://trezor.io/) - Open-source hardware wallet, one of the first on the market. [Explained](https://tokenalphabet.com/blog/trezor-explained-the-open-source-hardware-wallet-that-started-it-all)
- [Keystone](https://keyst.one/) - Air-gapped hardware wallet that signs via QR codes. [Explained](https://tokenalphabet.com/blog/keystone-explained-air-gapped-security-for-serious-crypto-investors)
- [Tangem](https://tangem.com/) - NFC card wallet that works with a phone. [Explained](https://tokenalphabet.com/blog/tangem-explained-can-a-card-replace-traditional-crypto-wallets)
- [SafePal](https://www.safepal.com/) - Hardware and mobile wallets in one ecosystem. [Explained](https://tokenalphabet.com/blog/safepal-explained-hardware-and-mobile-wallets-in-one-ecosystem)
- [Coldcard](https://coldcard.com/) - Bitcoin-only hardware wallet built for air-gapped signing with a microSD card.
- [BitBox02](https://bitbox.swiss/) - Swiss-made hardware wallet, also sold in a Bitcoin-only edition.
- [Blockstream Jade](https://blockstream.com/jade/) - Open-source Bitcoin hardware wallet with a camera for QR-based air-gapped use.
- [Foundation Passport](https://foundation.xyz/) - Open-source Bitcoin-only hardware wallet that signs via QR codes.
- [OneKey](https://onekey.so/) - Open-source multi-chain hardware wallets and companion apps.
- [GridPlus Lattice1](https://gridplus.io/) - Hardware wallet with a large touchscreen that shows readable transaction details.
- [Best hardware wallets for long-term investors](https://tokenalphabet.com/blog/best-hardware-wallets-for-long-term-crypto-investors) - Overview and comparison.

## Mobile wallets

- [Trust Wallet](https://trustwallet.com/) - Multi-chain mobile wallet. [Explained](https://tokenalphabet.com/blog/trust-wallet-explained-why-it-s-still-one-of-the-most-popular-mobile-wallets)

## Bitcoin wallets

- [Sparrow](https://sparrowwallet.com/) - Desktop Bitcoin wallet focused on coin control and privacy, works with most hardware wallets.
- [Electrum](https://electrum.org/) - Lightweight Bitcoin desktop wallet, in development since 2011.
- [BlueWallet](https://bluewallet.io/) - Bitcoin wallet for iOS and Android with watch-only wallets and multisig vaults.
- [Phoenix](https://phoenix.acinq.co/) - Self-custodial Bitcoin Lightning wallet by ACINQ.

## Multisig wallets

Wallets that need several approvals (for example 2 of 3 keys) before a transaction goes through, so one lost or stolen key does not drain the funds.

- [Safe](https://safe.global/) - Smart contract multisig for Ethereum and other EVM networks, formerly Gnosis Safe. [Explained](https://tokenalphabet.com/blog/multisig-wallets-explained-protecting-crypto-beyond-seed-phrases)
- [Casa](https://casa.io/) - Bitcoin multisig packaged as a service for individuals, with keys spread across devices.
- [Nunchuk](https://nunchuk.io/) - Bitcoin multisig wallet with collaborative custody and inheritance features.
- [Specter](https://specter.solutions/) - Specter Desktop, a Bitcoin multisig coordinator for hardware wallets.
- [Unchained](https://unchained.com/) - Collaborative custody: 2 of 3 Bitcoin multisig vaults where you hold two of the keys.
