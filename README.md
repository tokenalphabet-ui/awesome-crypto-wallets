## Hardware wallets

- [Ledger](https://www.ledger.com/) - Secure element hardware wallets with the Ledger Live app. [Explained](https://tokenalphabet.com/blog/ledger-explained-why-millions-trust-this-hardware-wallet-for-long-term-crypto-storage)
- [Trezor](https://trezor.io/) - Open-source hardware wallet, one of the first on the market. [Explained](https://tokenalphabet.com/blog/trezor-explained-the-open-source-hardware-wallet-that-started-it-all)
- [Keystone](https://keyst.one/) - Air-gapped hardware wallet that signs via QR codes. [Explained](https://tokenalphabet.com/blog/keystone-explained-air-gapped-security-for-serious-crypto-investors)
- [Tangem](https://tangem.com/) - NFC card wallet that works with a phone. [Explained](https://tokenalphabet.com/blog/tangem-explained-can-a-card-replace-traditional-crypto-wallets)
- [SafePal](https://www.safepal.com/) - Hardware and mobile wallets in one ecosystem. [Explained](https://tokenalphabet.com/blog/safepal-explained-hardware-and-mobile-wallets-in-one-ecosystem)
